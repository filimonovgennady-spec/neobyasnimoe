# НЕОБЪЯСНИМОЕ

Газета видеонаходок с Hacker News: ИИ, альтернативная история, конспирология, НЛО, загробная жизнь,
аномальные явления, полтергейст, святые и чудеса, шаманы, спиритизм, интервью и подкасты.

Публичный адрес: **https://filimonovgennady-spec.github.io/neobyasnimoe/**

## Откуда материалы

Два независимых источника, оба — Hacker News через Algolia API (без ключей):

1. **Рекомендации в комментариях** — YouTube-ссылка, которую один человек оставил другому.
   Собиралась тремя проходами: пары «тема + youtube», треды по темам, пересечение с общим корпусом
   видео-упоминаний HN (23 965 ссылок).
2. **Сабмиты** — посты HN, которые сами являются YouTube-видео (`story_url` содержит youtube).
   Это дало основную массу по НЛО, альтернативной истории, чудесам и шаманам: в комментариях этих
   тредов ссылки на видео почти не встречаются (в самом крупном треде про НЛО на 1113 комментариев — ноль).

Название и канал — YouTube **oEmbed** (без API-ключа), кадр — `i.ytimg.com/vi/<id>/mqdefault.jpg`
(320×180, чистое 16:9). Всё скачано локально через xray-прокси `127.0.0.1:10809`, потому что
`youtube.com` и `i.ytimg.com` из РФ напрямую не отвечают.

Подпись «о чём» у каждой заметки сгенерирована моделью по названию, каналу и цитате из обсуждения
(промпт запрещает добавлять факты, которых нет в данных). Это пересказ названия, а не проверка содержания.

## Что в газете

- передовая (самое рекомендуемое), затем полосы по рубрикам;
- поиск по заголовкам, каналам и рубрикам, фильтр по рубрике;
- «Моя подборка»: профиль из отметок ♥ в localStorage, аккаунт не нужен;
- хоткеи: `/` поиск, `Esc` сброс, `j`/`k` листать, `o` открыть, `l` в избранное, `x` вычеркнуть, `f` подборка, `?` справка;
- `⤓ JSON` — выгрузка выпуска и отметок (для передачи агенту).

## Пересборка

```
python tools/harvest_pairs.py       # тема + youtube в комментариях
python tools/harvest_pairs2.py      # вторая волна терминов
python tools/harvest_submissions.py # сабмиты-видео по темам
python tools/merge.py               # сведение источников + старый корпус
cp data/merged_raw.json data/themed_raw.json
python tools/enrich_themed.py       # oEmbed + превью (нужен прокси :10809)
python tools/labels.py && python tools/labels2.py   # подписи «о чём»
HN_COMMENTS=201068 python tools/build_paper.py      # data.js
python tools/deploy.py push         # публикация на GitHub Pages
```

## Честные оговорки

- «Рекомендовали N раз» — число комментариев HN со ссылкой на видео; для сабмитов это 1 (сам пост).
- Мёртвые ссылки (видео удалено) отброшены: 301 из 1060 в первой сборке.
- Газета не ручается за содержание: это след того, что люди находили интересным, а не проверка фактов.
